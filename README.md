## ✨ Features

Status 200 is built to make portfolio creation fast, clean, and professional:

- 📊 Dashboard to manage portfolios
- 🧩 Create, edit, and organize portfolio content
- 🖼️ Multiple portfolio templates
- 🔗 Publish public portfolio pages with shareable URLs
- 📝 Resume-to-portfolio parsing support
- 🌗 Light and dark mode support
- ⚡ Fast, responsive, and modern UI
- 🎨 Clean design system with a premium feel
- 🔒 Authentication flow with login, signup, reset password, and callback handling
- 💳 Razorpay integration for premium upgrade flow
- 🔍 SEO-friendly public portfolio pages

---

## 🛠 Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, custom UI components
- **Routing**: React Router
- **Backend**: Supabase
- **Payments**: Razorpay
- **Resume Parsing**: pdfjs-dist
- **Icons**: Lucide React

---

## 🎨 Design Philosophy

Status 200 focuses on a clean, premium, and recruiter-friendly experience:

- Minimal but expressive visual language
- Fast editing workflow
- Public pages optimized for readability
- Template-based design for different professional styles
- Dark mode for a modern, polished feel

---

## 🔐 Security & Data

Status 200 uses Supabase for authentication and portfolio data management.

- User-specific portfolio content is isolated by account
- Public pages are generated from structured portfolio data
- Payment-related actions are handled through serverless API routes
- SEO metadata is built for public portfolio discovery
